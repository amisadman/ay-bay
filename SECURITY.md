# Security Policy

## Supported Versions

Currently, only the latest `main` branch and the latest stable release of AyBay are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 1.1.0 | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of AyBay and its users' financial data very seriously. 

If you discover a security vulnerability within AyBay (e.g., an issue with local SQLite encryption, an exposed API key logic flaw in Walleo, or a bypass in the PIN/Biometric authentication), please **DO NOT** open a public issue.

Instead, please send an email privately to **sadman.swe@gmail.com** to report the vulnerability. We will endeavor to respond to your report within 48 hours and work with you to patch the issue before disclosing it publicly.
